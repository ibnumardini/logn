:/logen/

Simple Go log management library for daily, type-based file logging, optional Telegram error alerting, and monthly zip archiving.

  • Daily directories: Organizes logs automatically by YYYY/MM/DD.
  • Typed files: Splits output into info.log, warning.log, and error.log.
  • Telegram alerts: Forwards warning and error logs to a Telegram chat via bot token.
  • Monthly zip: Compresses past months into log_MM_YYYY.zip and optionally deletes old folders.

Shell Command 
go get -u github.com/ibnumardini/logn

§ 2.Configuration

Create logn_config.json in your project root (see logn_config_sample.json; token and chat ID below are redacted placeholders).

logn_config.json 
{
  "logn_is_active": true,
  "log": {
    "logn_dir": "log/",
    "logn_default_loc": "Asia/Jakarta",
    "logn_print_console": true
  },
  "tg": {
    "logn_tg_send": false,
    "logn_app_name": "Logn-App LOG",
    "logn_tg_token": "1416xxxxx:AAF3VOBjt7rIeO4tUL_dHxG0qxxxxxxxxx",
    "logn_tg_chat_id": "-4947xxxxx"
  },
  "zip": {
    "logn_is_zipped": false,
    "logn_dir_zip": "log_zip/",
    "logn_del_old_dir": false
  }
}
logn_is_active
Enable or disable Logn globally.
log
logn_dir (output path), logn_default_loc (timezone), logn_print_console (stdout echo).
tg
logn_tg_send (toggle), logn_app_name (header), logn_tg_token, logn_tg_chat_id.
zip
logn_is_zipped (monthly archive), logn_dir_zip (target path), logn_del_old_dir (cleanup).

§ 3.Usage

Pass a string or format values with fmt.Sprintf() / fmt.Sprintln(). Warning and error calls include file/line context and trigger Telegram reports when enabled.

Go Source 
logn.InfoLog("hello world")
logn.WarningLog(fmt.Sprintf("%s\n", warningInfo))
logn.ErrorLog(fmt.Sprintln("error message!"))

§ 4.Cron Zipping

Set logn_is_zipped: true, pass the CLI argument index to logn.CronZip(1) in init(), and execute your binary with logn_zip_run.

Go & CLI 
func init() {
    logn.CronZip(1)
}

// Run via cron:
// ./app logn_zip_run
