Logs that stay
out of your way.

Logn is a small Go logging library for applications that need daily, type-based logs without building a logging stack. Keep useful files, route warnings and errors to Telegram, and archive old data on your own schedule.

Start logging → Read the README ↗

01 / Daily files

Organize info, warning, and error output by year, month, and day.

02 / Typed logs

Use a focused API that makes the intent of each log line clear.

03 / Telegram

Optionally report warning and error logs through your bot.

Zip monthly log data and optionally remove old directories.

01 / install

Add Logn to a Go app.

Install the package with Go's package manager, then add a configuration file at your project root.

go get -u github.com/ibnumardini/logn

02 / configure

One JSON file. Four clear concerns.

{
  "logn_is_active": true,
  "log": {
    "logn_dir": "log/",
    "logn_default_loc": "Asia/Jakarta",
    "logn_print_console": true
  },
  "tg": {
    "logn_tg_send": false,
    "logn_app_name": "Logn-App LOG",
    "logn_tg_token": "1416xxxxx:AAF3VOBjt7rIeO4tUL_dHxG0qxxxxxxxxx",
    "logn_tg_chat_id": "-4947xxxxx"
  },
  "zip": {
    "logn_is_zipped": false,
    "logn_dir_zip": "log_zip/",
    "logn_del_old_dir": false
  }
}

logn_is_active
Enable or disable the Logn package.
log
Choose the log directory, timezone, and console output.
tg
Set Telegram reporting, app title, bot token, and chat ID.
zip
Enable zipping, choose its directory, and optionally delete old directories.

Keep credentials private. The values above are redacted examples. Copy the full structure from the sample config, then supply your own secrets locally.

03 / use

Three calls cover the common path.

Pass a string or a formatted value. Warning and error calls include source context and can be sent to Telegram when enabled.

logn.InfoLog("hello world")
logn.WarningLog(fmt.Sprintf("%s\n", warningInfo))
logn.ErrorLog(fmt.Sprintln("error message!"))

04 / archive

Zip logs when your app starts.

Enable the zip configuration, register the argument position with CronZip, and invoke your binary with logn_zip_run. The library checks the configured monthly path.

func init() {
    logn.CronZip(1)
}

./app logn_zip_run
